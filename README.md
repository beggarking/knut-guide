# 교통대 생활 가이드

한국교통대학교 충주캠퍼스 학생들이 직접 남긴 맛집·카페·숨은 장소·생활 꿀팁을 모은 비공식 가이드 사이트입니다.

- 분류별 보기: 음식점 / 카페 / 숨은장소 / 생활꿀팁 / 자유
- 이름·메뉴·위치·후기 검색 (관련도 순)
  - 된소리·오타·발음이 비슷한 말도 찾음: 자장면→짜장면, 부리토→부리또, 까페→카페
  - 초성 검색: ㅂㄹㄸ → 부리또
  - 뒤에 붙은 말 무시: 짜장면집 → 짜장면
  - 정확히 맞는 결과 아래에 '비슷한 결과'도 보여 줌
- 장소마다 👍 추천 / 👎 비추천 투표
- 학생 소개 많은 순 / 투표 많은 순 / 이름 순 / 최근 확인 순 정렬
- 분류는 주소로 바로 공유 가능 (예: `.../#카페`)

빌드 과정 없는 정적 사이트(HTML·CSS·JS)라 `index.html`을 브라우저로 열면 바로 동작합니다.

## GitHub Pages로 배포

1. 이 폴더를 GitHub 저장소에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`에서 열립니다.

## 데이터 갱신

엑셀(`장소 정리` 시트가 첫 번째 시트)을 고친 뒤 아래 명령으로 `data.js`를 다시 만듭니다. 외부 패키지는 필요 없습니다.

```bash
python tools/build_data.py 경로/데이터.xlsx
```

엑셀 칸: 이름, 위치, 지도, 분류, 확인한 날, 추천 수, 대표메뉴, 가격, 운영시간, 한줄 설명.
`확인 안 됨`인 칸은 사이트에 표시하지 않고, 한줄 설명은 ` / ` 기준으로 나눠 후기 목록으로 보여 줍니다.

## 투표 공유하기 (Supabase)

`config.js`가 비어 있으면 👍/👎 투표는 각자 브라우저에만 저장됩니다. 모든 방문자가 같은 투표 수를 보려면 무료 Supabase 프로젝트를 연결하세요.

1. https://supabase.com 에 가입하고 **New project**를 만듭니다.
2. 왼쪽 **SQL Editor**에 [`supabase.sql`](supabase.sql) 내용을 붙여 넣고 **Run**을 누릅니다.
3. **Project Settings → API**에서 `Project URL`과 `anon` `public` 키를 복사합니다.
4. `config.js`의 `url`, `key`에 넣고 커밋·push 하면 끝입니다.

anon 키는 공개용 키라 사이트에 넣어도 됩니다. 테이블은 읽기만 열려 있고, 쓰기는 한 번에 ±1만 바꾸는 `vote` 함수로만 할 수 있습니다.
같은 브라우저에서는 한 곳에 한 번만 투표되지만, 로그인이 없어서 작정하고 여러 번 누르는 것까지 막지는 못합니다.
